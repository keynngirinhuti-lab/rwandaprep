# RwandaPrep

RwandaPrep is a fast and responsive educational website that helps students find and access past examination papers, including national examinations, district-level examinations, and end-of-year examinations.

**Live website:** https://rwandaprep.netlify.app/

## The Problem

As a student, I found it difficult to find examination papers in one convenient place.

Before RwandaPrep, students could encounter several challenges:

* Buying books or syllabuses containing examination papers
* Asking teachers for papers, which may not always be readily available
* Searching through the NESA website for national examination papers
* Manually collecting district-level examination papers
* Finding end-of-year or Term 3 examination papers
* Searching through different websites that may have distracting advertisements or poor organization

This made finding useful practice material more time-consuming than it needed to be.

## The Solution

RwandaPrep organizes examination resources into a simpler interface so students can find papers more easily.

The website currently provides access to:

* National examination papers
* District-level examination papers
* End-of-year examination papers
* Available marking guides

The resources are organized with links to their respective sources.

## Features

* Responsive design
* Organized examination-paper categories
* Links to examination resources
* Simple navigation
* Mobile-friendly interface
* Fast access through a web browser

## Technologies

* HTML
* CSS
* JavaScript

## How I Built It

I used AI tools, including Gemini, to help accelerate parts of the development process.

However, I also worked directly with the code and personally organized and maintained the examination papers and links used by the website.

This project was an important step in learning how to combine coding with solving a real problem.

## What I Learned

RwandaPrep taught me more than just HTML, CSS, and JavaScript.

I learned how to:

* Turn a problem I experienced into a working product
* Think about the user experience when designing a website
* Organize information so users can find it more easily
* Deploy a website for real users
* Maintain resources and links after launch
* Think about how users discover and interact with a product

Most importantly, I learned that building a website is only one part of solving a problem. Understanding whether people actually use it and how they find it is also important.

## Usage

During S5 Term 3, RwandaPrep reached a peak of **81 users**, according to Google Analytics.

I am continuing to learn from how students use the platform and how resources can be organized more effectively.

## Project Status

RwandaPrep is an ongoing project.

I plan to continue improving the organization, usability, and availability of examination resources based on what I learn from users.
